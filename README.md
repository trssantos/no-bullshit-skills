# no-bullshit-skills

Practical skills for Claude and Claude Code. No bullshit allowed.

## Skills

### project-planning

Brainstorm and define a new project through guided discussion. Goes from fuzzy idea to a clear `project-summary.md` through a single conversation — no phases, no ceremony, no pile of documents.

Inspired by [GSD](https://github.com/glittercowboy/get-shit-done), stripped down to the core: ask questions, surface gray areas, capture decisions.

**Two versions:**

| File | Use With |
|------|----------|
| `project-planning/skill.md` | Claude Web (paste as project instructions or system prompt) |
| `project-planning/skill-claude-code.md` | Claude Code (place in `.claude/commands/` as a slash command) |
